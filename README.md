# Zodiac Basics

一个超简单的中英文星座基础分析网站，适合先部署到 GitHub Pages。

## 文件

- `index.html`：页面结构
- `styles.css`：样式
- `script.js`：中英文切换、星座选择和点击兴趣记录

## GitHub Pages 部署

1. 把这些文件推送到 GitHub 仓库。
2. 打开仓库的 `Settings`。
3. 进入 `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，文件夹选择 `/root`。
6. 保存后等待 GitHub 生成访问链接。
